The official website repository for **iAdvert Studio**, a specialized Meta and Facebook advertising agency led by Ratul Ahmed Shishir.

> **Private Repository** — This repository is maintained privately by Dew (`shishirdeew`). Source code and project assets are not intended for public redistribution.

**Live website:** [https://iadverts.site](https://iadverts.site)

## Overview

iAdvert Studio's website presents the agency's Meta Ads expertise, service approach, performance metrics, founder profile, return-on-ad-spend calculator, and case studies. The site is built as a fast, responsive static Astro application and deployed on Vercel.

## Features

- Responsive, polished landing page
- Interactive ROAS calculator
- Meta Ads service and case-study sections
- Founder profile and contact information
- Three.js-powered 3D hero experience
- Scroll reveal and reduced-motion support
- Privacy policy page
- Tailwind CSS-based design system
- SEO metadata, canonical URL, Open Graph, Twitter Cards, and JSON-LD
- Static output generated by Astro

## Tech Stack

| Technology | Purpose |
|---|---|
| [Astro](https://astro.build) | Static site generation and component architecture |
| [Tailwind CSS](https://tailwindcss.com) | Utility-first styling and responsive layout |
| [Three.js](https://threejs.org) | Interactive 3D hero scene |
| [Lucide](https://lucide.dev) | Interface iconography |
| [Vercel](https://vercel.com) | Production hosting and deployment |
